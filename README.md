# Viksit Garg — Developer Portfolio

A personal portfolio highlighting my work across AI/ML research, AI safety, LLM systems, edge AI, and product engineering.

## Portfolio route

Visit `/me` in the deployed app to explore the developer portfolio.

## Featured work

- [PromptShield](https://github.com/VIKSIT-GARG/prompt-shield) — prompt-injection scanning gateway for LLM applications.
- [SemPointer](https://github.com/VIKSIT-GARG/Sempointer) — research implementation and evaluation suite for random-access semantic memory.
- [BeforeCall](https://github.com/VIKSIT-GARG/BeforeCall) — evidence-backed meeting intelligence with a [live demo](https://beforecall.vercel.app/).
- [Food Traceability Graph](https://github.com/VIKSIT-GARG/food-traceability-graph) — supply-chain recall intelligence with a [live demo](https://food-traceability-demo.onrender.com/).
- [NOVA Edge KWS](https://github.com/VIKSIT-GARG/NOWA-KWS) — edge keyword spotting and cloud speech recognition pipeline.
- [Talk2Car VLM](https://github.com/VIKSIT-GARG/talk2car-ai_VLM) — vision-language model project.
- [SplitPe](https://github.com/VIKSIT-GARG/SplitPe) — experimental UPI and bill-splitting concept with a [demo](https://viksit-garg.github.io/SplitPe/).

## Stack

Next.js, React, TypeScript, CSS, Lucide icons, with project links to relevant repositories and demos.

## Local development

This repository uses Next.js and pnpm.

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000/me](http://localhost:3000/me).
